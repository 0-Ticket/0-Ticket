# 통합 체크리스트

박스마다 완료 조건을 확인하는 목록이다. 박스를 구현한 PR에서 해당 항목을 확인하고 표시한다.

- 기준 시나리오는 `docs/product-spec.md`의 S1~S5다.
- 각 항목은 가능하면 자동 테스트로 만든다. "테스트" 열에 테스트 이름을 적는다.
- 항목 ID는 `K`로 시작한다. 결정 대장의 `D-xxx`와 구분하기 위해서다.
- 상태: `⬜ 미구현` / `🟡 일부` / `✅ 통과`
