# 3단계: 테스트 · 수정 · PR 초안

`AGENTS.md`의 "완료 기준"을 모두 만족시킨 뒤 PR 제목과 본문 초안을 쓴다. push와 PR 생성은 사람이 한다.

계약 변경 그룹은 승인된 계획에 적힌 그룹 전체를 한 브랜치에서 검증한다. 시작할 때 `prompts/02-implement.md` 절차 1의 최신 이슈·승인 계획 대조를 다시 수행한다. 그룹 구성이나 조정 이슈 등이 달라졌으면 계획 갱신·재승인 후 진행한다.

## 절차

1. 아래 명령을 차례로 실행한다.

```bash
   uvx ruff format .
   uvx ruff check .
   uv run pytest
```

   화면 작업이면 `docs/frontend.md` "명령"의 타입 검사, 린트·포맷 검사, 테스트, 빌드도 차례로 실행한다.

2. 실패한 항목마다 원인을 한 줄로 설명하고 고친 뒤 다시 실행한다. 모두 통과할 때까지 반복한다.
   같은 실패를 3번 고쳐도 안 되면 멈추고 상황을 보고한다.
3. `tests/checklist.md`에서 영향받는 모든 박스(화면 작업이면 해당 화면)의 항목을 확인하고, 각 항목의 상태와 테스트 이름을 채운다. 그룹 작업은 시작 이슈의 박스만 확인하지 않는다.
4. `AGENTS.md`의 "완료 기준"을 하나씩 확인한다. 단일 이슈든 그룹이든 대상 이슈의 완료 기준과 영향받는 각 박스의 `docs/architecture.md` "완료 조건"을 문장 단위로 대조한다. 그룹 작업은 모든 그룹 이슈를 확인한다. 계약 변경이면 Schema와 생성 코드의 재현성, 손작성 fixture 검증, 필요한 저장 데이터 호환·migration·backfill 경계를 확인한다. 새 설정 값이 있으면 기본 설정 파일에 기본값·설명이 들어갔는지도 확인한다.
5. 고친 내용을 로컬에 커밋한다. 그룹 작업은 커밋 메시지에 조정 이슈 번호를 쓰고, 전체 변경을 같은 작업 브랜치에 담는다. 커밋 메시지에 AI 표시를 넣지 않는다.
6. PR 제목과 본문 초안을 쓴다. 대상 브랜치는 `main`이다.
   - 제목: `<type>(<scope>): <summary> (#<번호>)`. squash 머지되면 이 제목이 `main`의 커밋 메시지가 된다
   - 본문은 `.github/PULL_REQUEST_TEMPLATE.md` 형식을 따른다
   - 단일 이슈: 관련 이슈는 `Closes #<번호>`로 연결한다. 머지되면 이슈가 닫힌다
   - 계약 변경 그룹: 제목과 커밋 메시지에는 조정 이슈 번호를 쓰고, 본문에는 그룹의 모든 이슈를 이슈마다 별도 `Closes #<번호>` 줄로 연결한다
   - 변경 내용: 바꾼 것. 데이터 계약이 바뀌었으면 "데이터 계약 변경"으로 따로 표시
   - 이유: 왜 바꿨는지. 새 라이브러리를 넣었다면 그 이유
   - 테스트 방법: 실행한 명령과 결과, 확인한 모든 영향 박스의 체크리스트 ID
7. 사람이 실행할 명령을 함께 출력한다.

```bash
   git push -u origin <브랜치>
```

   해당 작업 브랜치에 대한 이 명령을 출력하고, 사람이 실행한 뒤 GitHub에서 base를 `main`으로 골라 PR을 만든다. 계약 변경 그룹도 전체 이슈를 포함한 PR 하나를 준비한다.

## 하지 않을 것

- 테스트를 지우거나 건너뛰게(skip) 만들어 통과시키지 않는다. (`@pytest.mark.llm`으로 실제 모델 테스트를 분리하는 것은 예외)
- 린트 규칙을 끄거나 예외 주석으로 넘기지 않는다. 꼭 필요하면 PR 초안에 이유를 적는다.
- `git push`, `gh pr create` 등 GitHub에 쓰는 명령을 직접 실행하지 않는다.
- 커밋 메시지와 PR 초안에 `Co-Authored-By`, "Generated with" 같은 AI 표시를 넣지 않는다.

## 출력

- 완료 기준 충족 여부 (항목별 ✅ / ❌)
- 그룹 작업이면 이슈별·영향 박스별 완료 기준 충족 여부와 체크리스트 ID (항목별 ✅ / ❌)
- PR 제목과 본문 초안 (복사해서 바로 쓸 수 있게 코드 블록으로, 그룹은 모든 이슈의 별도 `Closes` 줄 포함)
- 사람이 실행할 push 명령
