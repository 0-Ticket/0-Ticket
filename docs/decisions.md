# 결정 대장

팀이 정한 도구와 방식이다. 여기서 "확정"인 것만 코드에 들어간다. ID는 새 하네스에서 처음부터 매긴다. `old` 브랜치의 결정 번호와는 관계없다.

## 쓰는 법

- **정할 것이 생기면** 계획 이슈에 적거나 아래 "논의 중"에 한 줄을 추가한다. `/soc-plan`이 계획을 검토하다 확정되지 않은 도구를 발견하면 안건으로 올린다.
- **정해지면** "확정"으로 옮기고 "기록"에 한 줄을 남긴다. 상태는 사람만 정한다. 사람이 정한 것을 AI가 받아 적는 것은 괜찮다(`/soc-plan` 확정 단계).
- **바꿀 때는** 같은 ID의 내용을 고치고 기록에 남긴다. 없앨 때는 "보류 · 폐기"로 옮긴다. 번호는 다시 쓰지 않는다.

## 논의 중

| ID | 안건 | 선택지 · 메모 | 정할 때 |
|---|---|---|---|
| D-011 | 설정 파일 형식 | TOML / YAML / 환경변수만 | 설정이 처음 필요한 이슈 |

| D-013 | 화면 세부 도구 | UI 라이브러리, 서버 데이터 관리, 패키지 관리자, 화면 테스트 | 첫 화면 이슈 |

## 확정

| ID | 결정 | 메모 |
|---|---|---|
| D-001 | 백엔드는 Python 3.13 + uv. 린트·포맷 ruff, 테스트 pytest | CI와 같은 명령 |
| D-002 | 에이전트는 OpenAI Agents SDK로 만든다. SDK 트레이싱은 끈다 | 트레이싱은 기본으로 켜져 있고 모델 입력·출력을 OpenAI 서버로 보낸다. 알럿·로그가 D-003 제공자 밖으로 나가지 않게 한다(`docs/security.md`) |
