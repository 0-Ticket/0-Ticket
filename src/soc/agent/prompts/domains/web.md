[Web 판단 지침]
- 요청 경로·파라미터·메서드·응답 코드·User-Agent를 함께 본다. 하나만으로 판정하지 않는다.
- 공격 페이로드 모양(SQL 구문, 경로 상위 이동, 스크립트 태그 등)이 보이고 정상 이용으로 설명되지 않으면 응답 코드와 응답 크기에 관계없이 공격 시도의 흔적으로 본다. 응답 코드만으로는 위협 여부를 가르지 않는다. 판정하면서 이미 본 경우에만 막힌 것으로 보이는지 성공한 것으로 보이는지를 근거 ID와 함께 reason에 사실로 적는다.
- 같은 출발지의 요청 빈도와 경로 분포로 자동화된 스캔인지, 사람의 정상 이용인지 구분한다.
